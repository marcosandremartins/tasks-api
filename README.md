<h2 id="started">🚀 Getting started</h2>

<h3>Prerequisites</h3>

- [Adoptium Java 21](https://adoptium.net/temurin/releases/?version=21)
- [Maven](https://maven.apache.org/)
- [Make](https://www.make.com/en/integrations/util)

<h3>Cloning</h3>

```bash
git clone git@github.com:marcosandremartins/tasks-api.git
```

<h3>Starting Api</h3>

```bash
cd tasks-api
make run
```

<h3>Run Tests</h3>

```bash
cd tasks-api
make test
```
